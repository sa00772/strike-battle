플레이 라운지

스마트폰으로 함께 즐기는 도장·체육관 실시간 게임 모음입니다.
게임을 고르면 PC 점수판이 열리고, 선수들은 점수판의 QR 코드로 입장합니다.

모션 센서

타격 대결

청팀과 홍팀이 휴대폰을 휘둘러 타격 수로 겨룹니다.

  • 가속도 센서로 타격 감지
  • 라운드·휴식 타이머
PC 점수판 열기 → 뛰어다니기

사이버 쟁탈전

체육관 양 끝의 기지 화면을 터치해 상대 깃발을 빼앗습니다.

  • 기지 기기 2대 필요
  • 깃발 쿨타임, 승리 폭죽
PC 점수판 열기 → 반응속도

네온 터치 대전

화면에 신호가 뜨는 순간 가장 먼저 터치한 팀이 점수를 얻습니다.

  • 부정 출발은 라운드 실격
  • 팀별 최고 반응 기록 표시
PC 점수판 열기 → 팀 전략

디지털 판 뒤집기

9x9 판의 칸을 눌러 우리 팀 색으로 뒤집습니다. 1분 30초 타이머와 실시간 점수 바로 시비 없이 승부가 갈립니다.

  • 사범님 미션 덱: 돌발 미션 + 효과음
  • 대화면·휴대폰 긴급 연출
PC 점수판 열기 →
사용 방법
1. PC에서 게임 카드를 눌러 점수판을 열고 관리자 비밀번호로 로그인합니다.
2. 청팀·홍팀 QR 코드를 각 선수의 스마트폰으로 스캔하고 참가 코드를 입력합니다.
3. 어느 게임에서든 점수판의 🚨 미션 덱으로 돌발 미션을 보내면 경기가 멈추고 대화면·휴대폰에 긴급 연출이 나옵니다.
4. 점수판의 시작 버튼을 누르면 경기가 시작됩니다. 점수판을 열 때마다 독립된 경기방이 만들어집니다.
