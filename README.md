# 청팀 vs 홍팀 모션 센서 타격 대결

휴대폰을 휘두르면 가속도 센서(DeviceMotionEvent)가 타격을 감지해서 PC 전광판에 실시간으로 점수가 올라가는 웹 프로그램입니다.

## 폴더 구조
```
strike-battle/
├─ package.json
├─ server.js            # Express + Socket.io 서버
└─ public/
   ├─ index.html        # PC 점수판 (QR 2개 + 타이머)
   └─ mobile.html       # 모바일 센서 패드
```

## 실행 방법
1. Node.js 18 이상 설치 (https://nodejs.org)
2. 터미널에서 프로젝트 폴더로 이동 후:
   ```bash
   npm install
   npm start
   ```
3. 터미널에 감지된 로컬 IP와 접속 주소가 출력됩니다.
   ```
   PC 점수판   : https://192.168.0.12:3000/
   청팀 모바일 : https://192.168.0.12:3000/mobile.html?team=blue
   홍팀 모바일 : https://192.168.0.12:3000/mobile.html?team=red
   ```
4. PC 브라우저에서 점수판 주소를 엽니다. (처음엔 보안 경고 → "고급 → 계속 진행")
5. 각 선수가 휴대폰 카메라로 자기 팀 QR 코드를 스캔합니다. (PC와 휴대폰은 **같은 Wi-Fi**)
6. 휴대폰에서 보안 경고를 한 번 넘기고 **[센서 시작]** 버튼을 누릅니다. (iOS는 권한 팝업 → 허용)
7. PC 점수판에서 **시작**을 누르면 타격이 집계됩니다.

## 왜 HTTPS인가요?
iOS Safari와 최신 Android Chrome은 **보안 연결(HTTPS)에서만** 모션 센서를 허용합니다.
`http://192.168.x.x` 로 접속하면 센서 이벤트가 아예 들어오지 않습니다.
그래서 서버가 시작할 때 자체 서명 인증서를 `./certs`에 자동 생성해 HTTPS로 서비스합니다.
(`npm run start:http`는 센서 제약이 없는 환경이나 PC 화면 테스트용입니다.)

## 사용법
| 기능 | 설명 |
|---|---|
| 시작 / 일시정지 / 초기화 | 현재 모드(라운드·휴식)의 타이머 제어. 초기화는 점수를 건드리지 않음 |
| 3분 / 1분 / 30초 | 현재 모드(라운드 또는 휴식)의 시간을 선택. 타이머가 해당 시간으로 초기화되며 진행 중에는 잠김 |
| 라운드 / 휴식 | 모드 전환 (기본 3분 / 1분) |
| 점수 0점으로 초기화 | 양 팀 점수 리셋 (확인창 표시) |
| 시간 종료 | 타격 집계 중단 + 승패 오버레이 표시. 이어서 **시작**을 누르면 라운드→휴식→라운드 순으로 넘어감 |
| 임계값 슬라이더 (모바일) | 세기 미터의 노란 선이 임계값. 반응이 없으면 낮추고, 살짝만 흔들어도 올라가면 높이기 |

- 쿨타임: 0.3초 (클라이언트) + 서버측 0.25초 연타 방지
- 타격 집계는 **서버가 라운드 진행 중일 때만** 인정합니다 (모바일의 임의 조작 방지).
- 시간 변경: `ROUND_SEC=120 REST_SEC=30 npm start` (Windows PowerShell: `$env:ROUND_SEC=120; npm start`)
- 포트 변경: `PORT=8080`, IP 수동 지정: `HOST_IP=192.168.0.50`
- 휴대폰 임계값 테스트용 수동 타격 버튼: 주소 뒤에 `&debug=1`

## 문제 해결
- **QR이 안 나옴**: 점수판이 CDN(cdnjs)의 qrcode.js를 불러옵니다. 인터넷이 없는 환경이면 `qrcode.min.js`를 내려받아 `public/`에 넣고 `index.html`의 `<script src>`를 `/qrcode.min.js`로 바꾸세요. (그 전까지는 QR 아래 주소를 직접 입력해도 됩니다.)
- **접속이 안 됨**: 같은 Wi-Fi인지, PC 방화벽에서 3000 포트가 허용되는지 확인. 게스트 Wi-Fi는 기기 간 통신을 막는 경우가 많습니다.
- **점수판 QR의 IP가 이상함**: 가상 어댑터(VMware, Docker 등)가 잡힌 경우입니다. 점수판 가운데의 "QR 주소" 드롭다운에서 고르거나 `HOST_IP`로 지정하세요.
- **iOS에서 센서 권한 팝업이 안 뜸**: HTTPS인지 확인. 이전에 거부했다면 Safari를 완전히 종료 후 다시 접속하세요.
- **진동이 안 됨**: iOS Safari는 `navigator.vibrate`를 지원하지 않습니다. 화면 깜빡임으로 피드백됩니다.

## 접근 제어 (관리자 비밀번호 / 참가 코드)
| 환경변수 | 용도 |
|---|---|
| `ADMIN_PASSWORD` | PC 점수판 로그인 비밀번호. 맞아야 타이머·점수 조작과 QR 표시 가능 |
| `ACCESS_CODE` | 모바일 패드 입장 코드. 점수판 화면에 표시되며 참가자가 휴대폰에서 입력 |

- 비워 두면 해당 보호는 꺼집니다.
- 틀린 코드를 5번 입력하면 해당 IP가 60초간 잠깁니다.
- **내 PC 실행 (PowerShell):** `$env:ADMIN_PASSWORD="내비밀번호"; $env:ACCESS_CODE="1234"; npm start`
- **Railway:** 서비스의 Variables 탭에 `ADMIN_PASSWORD`, `ACCESS_CODE`를 추가하면 자동 재배포됩니다.
- 코드를 바꾸면 이전 코드를 저장한 기기도 다시 입력해야 합니다.
