# 플레이 라운지 (Play Lounge)

스마트폰으로 함께 즐기는 도장·체육관 실시간 게임 모음입니다. 메인 주소(`/`)의 **메뉴**에서 게임을 골라 PC 점수판을 열고, 선수들은 점수판의 QR 코드로 입장합니다.

| 게임 | PC 점수판 주소 | 선수 화면 |
|---|---|---|
| 타격 대결 | `/scoreboard.html?game=strike` | `mobile.html` |
| 피구 | `/scoreboard.html?game=dodge` | `dodge-ref.html` (심판) |
| 반응속도 게임 | `/scoreboard.html?game=neon` | `neon-pad.html` |
| 디지털 판 뒤집기 | `/scoreboard.html?game=flip` | `flip-pad.html` |

> 이전 버전의 PC 점수판 주소(`/`)는 이제 메뉴 화면입니다. 점수판은 `scoreboard.html`입니다.

휴대폰을 휘두르면 가속도 센서(DeviceMotionEvent)가 타격을 감지해서 PC 전광판에 실시간으로 점수가 올라가는 웹 프로그램입니다.

## 폴더 구조
```
strike-battle/
├─ package.json
├─ server.js            # Express + Socket.io 서버
└─ public/
   ├─ index.html        # PC 점수판 (QR 2개 + 타이머)
   └─ mobile.html       # 모바일 센서 패드
```

## 실행 방법
1. Node.js 18 이상 설치 (https://nodejs.org)
2. 터미널에서 프로젝트 폴더로 이동 후:
   ```bash
   npm install
   npm start
   ```
3. 터미널에 감지된 로컬 IP와 접속 주소가 출력됩니다.
   ```
   PC 점수판   : https://192.168.0.12:3000/
   청팀 모바일 : https://192.168.0.12:3000/mobile.html?team=blue
   홍팀 모바일 : https://192.168.0.12:3000/mobile.html?team=red
   ```
4. PC 브라우저에서 점수판 주소를 엽니다. (처음엔 보안 경고 → "고급 → 계속 진행")
5. 각 선수가 휴대폰 카메라로 자기 팀 QR 코드를 스캔합니다. (PC와 휴대폰은 **같은 Wi-Fi**)
6. 휴대폰에서 보안 경고를 한 번 넘기고 **[센서 시작]** 버튼을 누릅니다. (iOS는 권한 팝업 → 허용)
7. PC 점수판에서 **시작**을 누르면 타격이 집계됩니다.

## 왜 HTTPS인가요?
iOS Safari와 최신 Android Chrome은 **보안 연결(HTTPS)에서만** 모션 센서를 허용합니다.
`http://192.168.x.x` 로 접속하면 센서 이벤트가 아예 들어오지 않습니다.
그래서 서버가 시작할 때 자체 서명 인증서를 `./certs`에 자동 생성해 HTTPS로 서비스합니다.
(`npm run start:http`는 센서 제약이 없는 환경이나 PC 화면 테스트용입니다.)

## 경기방 (이용자별 독립 화면)
- 점수판을 열 때마다 **독립된 경기방**이 만들어집니다. 점수·타이머·접속자는 방마다 따로 관리되어, 다른 사람이 쓰는 점수판과 섞이지 않습니다.
- 주소에 `?room=A7K2PQ`가 붙으며, 새로고침해도 같은 방이 유지됩니다. 점수판 가운데에서 방 ID를 확인할 수 있습니다.
- 점수판의 QR 코드에는 방 ID가 포함되어 있어, 스캔한 사람은 그 방에만 입장합니다.
- 새 경기방이 필요하면 점수판의 **새 경기방 만들기**를 누르세요. (점수판 주소의 `?room=...` 부분을 빼고 접속해도 됩니다.)
- 접속자가 없는 방은 30분 뒤 자동 삭제되며, 서버를 재시작하면 모든 방의 점수가 사라집니다.

## 사용법
| 기능 | 설명 |
|---|---|
| 시작 / 일시정지 / 초기화 | 현재 모드(라운드·휴식)의 타이머 제어. **초기화는 시간과 양 팀 점수를 모두 0으로 되돌림** (점수가 있으면 확인창 표시) |
| 3분 / 1분 / 30초 | 현재 모드(라운드 또는 휴식)의 시간을 선택. 타이머가 해당 시간으로 초기화되며 진행 중에는 잠김 |
| 라운드 / 휴식 | 모드 전환 (기본 3분 / 1분) |
| 점수 0점으로 초기화 | 양 팀 점수 리셋 (확인창 표시) |
| 시간 종료 | 타격 집계 중단 + 승패 오버레이 표시. 이어서 **시작**을 누르면 라운드→휴식→라운드 순으로 넘어감 |
| 임계값 슬라이더 (모바일) | 세기 미터의 노란 선이 임계값. 반응이 없으면 낮추고, 살짝만 흔들어도 올라가면 높이기 |

- 쿨타임: 0.3초 (클라이언트) + 서버측 0.25초 연타 방지
- 타격 집계는 **서버가 라운드 진행 중일 때만** 인정합니다 (모바일의 임의 조작 방지).
- 시간 변경: `ROUND_SEC=120 REST_SEC=30 npm start` (Windows PowerShell: `$env:ROUND_SEC=120; npm start`)
- 포트 변경: `PORT=8080`, IP 수동 지정: `HOST_IP=192.168.0.50`
- 휴대폰 임계값 테스트용 수동 타격 버튼: 주소 뒤에 `&debug=1`

## 문제 해결
- **QR이 안 나옴**: 점수판이 CDN(cdnjs)의 qrcode.js를 불러옵니다. 인터넷이 없는 환경이면 `qrcode.min.js`를 내려받아 `public/`에 넣고 `index.html`의 `<script src>`를 `/qrcode.min.js`로 바꾸세요. (그 전까지는 QR 아래 주소를 직접 입력해도 됩니다.)
- **접속이 안 됨**: 같은 Wi-Fi인지, PC 방화벽에서 3000 포트가 허용되는지 확인. 게스트 Wi-Fi는 기기 간 통신을 막는 경우가 많습니다.
- **점수판 QR의 IP가 이상함**: 가상 어댑터(VMware, Docker 등)가 잡힌 경우입니다. 점수판 가운데의 "QR 주소" 드롭다운에서 고르거나 `HOST_IP`로 지정하세요.
- **iOS에서 센서 권한 팝업이 안 뜸**: HTTPS인지 확인. 이전에 거부했다면 Safari를 완전히 종료 후 다시 접속하세요.
- **진동이 안 됨**: iOS Safari는 `navigator.vibrate`를 지원하지 않습니다. 화면 깜빡임으로 피드백됩니다.

## 접근 제어 (관리자 비밀번호 / 참가 코드)
| 환경변수 | 용도 |
|---|---|
| `ACCESS_CODE` | 모바일 패드 입장 코드. 점수판 화면에 표시되며 참가자가 휴대폰에서 입력 |

- 비워 두면 해당 보호는 꺼집니다.
- 틀린 코드를 5번 입력하면 해당 IP가 60초간 잠깁니다.
- **내 PC 실행 (PowerShell):** `$env:ACCESS_CODE="1234"; npm start`
- **Railway:** 서비스의 Variables 탭에 `ACCESS_CODE`를 추가하면 자동 재배포됩니다.
- 코드를 바꾸면 이전 코드를 저장한 기기도 다시 입력해야 합니다.

## 피구
메뉴에서 **피구**를 눌러 점수판을 열면 **가운데에 `심판 입장` QR**이 나옵니다. 심판이 휴대폰으로 스캔해 **청팀·홍팀 양쪽 점수/인원을 모두 조작**합니다(선수 개인 QR은 없습니다). 점수판(PC)에서도 같은 조작을 할 수 있습니다.

**모드 (심판 휴대폰 또는 점수판 `피구 모드`, 바꾸면 점수·생존 상태가 초기화됩니다)**
- **생존 피구**: 공에 맞은 선수가 나올 때마다 심판이 해당 팀 `−1`(아웃), 부활은 `+1`. 팀 인원수는 `인원 −/+`로 설정(기본 5명). 한 팀이 전멸하면 상대 팀 승리, 시간이 끝나면 생존 인원이 많은 팀이 승리합니다.
- **점수 피구**: 죽지 않고, 명중할 때마다 심판이 해당 팀 `+1`(실수는 `−1`). 시간이 끝나면 점수가 높은 팀이 승리합니다.

**피구 전용 이벤트 (심판 휴대폰·점수판 버튼, 점수판에 화면·소리 연출)**: 전체 부활 / 얼음! / 땡!

## 반응속도 게임
화면이 **초록불**로 바뀌는 순간 청팀과 홍팀 중 **먼저 버튼을 누른 쪽**이 +1점을 얻습니다.

1. 메뉴에서 **반응속도 게임**을 눌러 점수판을 열고, 청팀·홍팀 QR을 선수가 스캔합니다. (1대1 대결이면 팀당 1명)
2. 점수판의 **시작**을 누르면 라운드 동안 반복됩니다. (2~5초 무작위 대기 → 초록불 → 결과 → 다음 판)
3. 초록불 전(검은 화면 "준비…")에 누르면 **부정 출발**로 그 라운드는 실격입니다.
4. 초록불 후 3초 안에 아무도 누르지 않으면 시간 초과입니다.
5. 점수판 중앙에 결과와 반응 시간, 팀별 **최고 기록**이 표시됩니다.

- 반응 시간은 서버 기준이라 와이파이 상태에 따라 수십 ms 오차가 있을 수 있습니다.

## 디지털 판 뒤집기 (9x9)
- 선수들이 휴대폰·태블릿의 9x9 판에서 칸을 눌러 **우리 팀 색으로 뒤집습니다.** 상대 색 칸을 누르면 빼앗고, 점유한 칸 수가 점수입니다.
- 점수판 맨 위에 **실시간 점수 바**(청/홍/남은 칸)가 표시되고, 기본 타이머는 **1분 30초**입니다. 종료 시 점수가 그대로 남아 시비를 줄입니다.
- 판은 모두 비어 있는 상태로 시작합니다. 초기화 버튼은 시간·점수·판을 모두 비웁니다.

## 돌발 미션 덱 (모든 게임 공통)
점수판 오른쪽 위의 **🚨 미션 덱**(또는 사범님 휴대폰 리모컨)에서 미션을 보냅니다.
1. **직접 입력:** 문구(최대 80자)와 제한 시간(5~60초), 효과음(긴급 경보음 / 환호성 / 땡- 틀렸습니다 / 없음)을 고르고 **미션 발송**. 엔터키로도 발송됩니다.
2. **프리셋:** 자주 쓰는 미션 버튼을 누르면 즉시 발송됩니다. 문구를 입력한 뒤 *프리셋으로 저장*하면 추가되고, ×로 삭제합니다. (프리셋은 그 기기의 브라우저에 저장)
3. **연출:** 게임이 일시정지되고 대화면·모든 선수 휴대폰에 `🚨 EMERGENCY MISSION! 🚨`, 미션 문구, 카운트다운이 나옵니다. 휴대폰은 진동하며, *선수 휴대폰에서도 소리 재생*을 켜면 휴대폰에서도 소리가 납니다. 대화면 PC 스피커는 항상 재생됩니다.
4. **재개:** 시간이 끝나거나 **게임 재개**를 누르면 휘파람(삐-익!)과 함께 타이머가 이어서 진행됩니다. 이미 일시정지 상태에서 보낸 미션은 끝나도 자동 재개되지 않습니다.
- **사범님 리모컨:** 미션 덱 아래 QR을 휴대폰으로 스캔하면 `deck.html`이 열립니다. 관리자 비밀번호를 입력하면 미션 발송과 타이머 시작·정지를 할 수 있습니다.
- 소리가 안 나면 점수판 화면을 한 번 클릭하세요(브라우저 정책). PC 소리와 볼륨도 확인하세요.


## 태권도 경기 (공인품새 토너먼트 / 자유품새 컷오프)

메뉴의 **태권도 경기** 카테고리에서 시작합니다. (종합놀이 = 기존 게임들)

**진행 순서**
1. 공인품새 대전 / 자유품새 대전 클릭 → 관리자 비밀번호 입력 (대회마다 독립된 대회 코드 생성)
2. 참가 선수를 한 줄에 한 명씩 `이름 / 소속` 으로 입력, 심판 수(1~5명) 선택
3. 화면의 QR을 심판 휴대폰으로 스캔 → 참가 코드 입력 → 본인 심판 번호 선택 (한 번호는 한 기기만 사용)
4. `대진 추첨 시작` → 인원수에 맞는 무작위 대진 생성 (심판이 1명 이상 접속해야 경기 시작 가능)
5. 경기 시작 → 심판들이 휴대폰으로 채점·제출 → 관리자가 감점(시간/경계선/재시작) 입력 후 `점수 확정`
   (전원 제출 전에도 `강제 마감`으로 제출된 점수만 집계 가능)

**공인품새 (토너먼트)**: 설정에서 품새 범위(태극 1장 ~ 일여 중 시작·끝 선택)와 품새 수(1~2개)를 고릅니다. `대진 추첨 시작` 때 범위 안에서 품새를 한 번 무작위로 뽑아 **모든 경기가 같은 품새**를 합니다(대진표 위에 표시). 청·홍 두 선수가 품새를 차례로 수행하고 품새마다 채점하며 점수는 평균이고, 높은 쪽이 승리합니다. **동점이면 아직 하지 않은 다른 품새를 하나 더** 해서 그 품새 점수로 승부를 가리며, 또 동점이면 새 품새를 또 하나 더 합니다.
- 정확성 4.0 − 작은 실수 0.1 − 큰 실수 0.3, 표현성 = 속도와 힘 + 리듬과 템포 + 기의 표현 (각 0.5~2.0)

**자유품새 (컷오프)**: 선수가 한 명씩 연기. 8명 이하 결승 / 9~19명 준결승(상위 8명)→결승 / 20명 이상 예선(2~3개 조, 조별 상위 50%)→준결승→결승. 컷 경계 동점자는 함께 진출.
- 기술 6항목(뛰어 옆차기 · 다단계 발차기 · 회전 발차기 · 연속 발차기 · 아크로바틱 · 기본동작) + 표현 4항목, 항목당 0~1.0

**공통 규칙**: 심판 5명일 때만 최고·최저 점수를 제외하고 평균, 4명 이하는 전원 평균. 감점은 평균 뒤에 적용 (시간 −0.3, 경계선 −0.3, 재시작 −0.6[공인품새만]).
**주의**: 점수 항목 배점·동점 규칙 일부는 WT 규정을 바탕으로 한 해석입니다. 실제 대회 전 사범님 기준에 맞는지 확인하세요. 기록은 서버 메모리에만 있고 12시간 뒤 삭제됩니다.

**진행 큐 (메인 PC)**: 경기 중 관리자 화면의 `경기 진행` 영역에서 버튼으로 호령을 내립니다. 누르면 효과음 + 음성 + 전체화면 글자(먹빛 한지 질감)가 나옵니다.
- 공인품새: 입장 → 경례 → 준비 → 시작 → 바로 → 쉬어 → 퇴장
- 자유품새: 입장 → 경례 → 준비 → 바로 → 쉬어 → 퇴장
- 다음에 누를 버튼은 노란 테두리로 표시됩니다. 효과음/음성은 체크박스로 끌 수 있습니다.

**연기 시간**: 스톱워치가 있습니다. 공인품새는 `시작`을 누르면 자동으로 시간이 흐르고 `바로`에서 멈춥니다. 자유품새는 `⏱ 시작` 버튼으로 직접 시작하고 `바로`에서 멈춥니다. 적정 시간(공인품새 90초 이내, 자유품새 100초 이내, 화면에서 수정 가능)을 벗어나면 경고가 뜨니 시간 감점 버튼을 눌러 주세요.


## 타격 대결 · 반응속도 — 최대 4팀, 팀 이름 설정
점수판 가운데의 **참가 팀 수(2~4팀)** 로 팀을 늘리고, **팀 이름 설정**에서 이름을 바꿉니다(기본 `1팀, 2팀, 3팀, 4팀`, 최대 8자). 팀마다 QR이 나오고 각 팀 휴대폰 화면에도 설정한 이름이 표시됩니다. 팀 수를 줄이면 빠지는 팀의 기기는 자동으로 연결이 끊기고 점수가 지워집니다. 시간이 끝나면 가장 높은 점수의 팀이 승리(동점 1위가 여럿이면 무승부)입니다. 판 뒤집기·피구는 기존처럼 2팀입니다.

## 타이머 직접 설정
모든 점수판 게임(타격·피구·반응속도·판 뒤집기)에서 프리셋(3분/1분30초/1분/30초) 외에 `분`·`초`를 직접 입력해 **원하는 시간(5초~99분 59초)** 으로 설정할 수 있습니다. 라운드/휴식 각각 적용되며 진행 중에는 잠깁니다.


## 심판 채점 화면 (공인품새·자유품새)
- **공인품새**: 정확성 4.0(작은 실수 `-0.1`, 큰 실수 `-0.3` 큰 버튼을 누를 때마다 감점 횟수가 늘고 `↶`로 취소) + 속도와 힘 · 강유/완급/리듬 · 기의 표현(각 0.5~2.0, 값을 누르면 선택창). 청·홍 대결은 항목명을 가운데 두고 양쪽에 점수와 감점 버튼이 배치됩니다.
- **자유품새**: 기술 영역 6항목 + 표현 영역 4항목(각 0~1.0, 기본 1.0)과 표현 영역 감점 `-0.1`/`-0.3`.
- 상단에 선수·품새·영역별 점수·합계가 실시간으로 보이고 `결과전송`을 누르면 확인 후 제출합니다.

## 홈페이지 공지사항
`public/notices.json` 을 수정하면 홈페이지 "종합놀이" 위의 공지가 바뀝니다. 형식: `[{"date":"2026-11-17","text":"공지 내용"}]` (최신 날짜 1건이 한 줄로 보이고, 더 있으면 `더보기`로 펼쳐집니다. 최대 8건)

## 회원 시스템

- 가입 항목: 이름, 소속(도장/학교/기타 + 이름), 아이디, 비밀번호, 전화번호 → `/login.html`
- 로그인하면 `/me.html`(내 공간)에서 **선수 명단**과 **경기 기록**을 관리합니다.
- 회원마다 **개인 DB 파일**(`data/members/<번호>.db`)을 따로 사용하고, 회원 정보·세션은 `data/main.db`에 저장됩니다.
- 로그인한 상태에서 점수판을 열면 끝난 경기(타격·피구·반응속도·판 뒤집기)가 그 회원 DB에 자동 저장됩니다.
- 비밀번호는 scrypt 해시로만 저장, 세션은 HttpOnly 쿠키(30일). 탈퇴하면 개인 DB 파일까지 삭제됩니다.
- Node **22.13 이상** 필요(내장 `node:sqlite` 사용, 별도 설치 없음).
- **Railway**: 서비스에 Volume 을 만들어 `/data` 에 연결하고 환경변수 `DATA_DIR=/data` 를 설정해야 재배포해도 데이터가 유지됩니다.
- **아이디·비밀번호 찾기**: 로그인 화면의 '아이디 · 비밀번호 찾기'. 이름+전화번호로 아이디(일부 가림)를 찾고, 아이디+이름+전화번호가 모두 맞으면 새 비밀번호를 정할 수 있습니다. 아이디별 5회 실패 시 15분 잠금, 재설정하면 모든 기기의 로그인이 해제됩니다. (문자/이메일 인증은 별도 유료 서비스가 필요해 쓰지 않았습니다.)
- **기기 제한**: 한 아이디는 최대 5대까지 동시에 로그인할 수 있고, 6번째 기기에서 로그인하면 가장 오래된 기기가 자동 로그아웃됩니다.
- **회원 전용**: 점수판·태권도 경기 운영·미션 리모컨은 로그인한 회원만 열 수 있습니다(관리자 비밀번호는 폐지). 선수·심판 휴대폰은 QR/참가 코드로 가입 없이 입장합니다.
- Railway 는 Volume 마운트 경로(`RAILWAY_VOLUME_MOUNT_PATH`)를 자동으로 인식합니다.

## 마스터 계정 (회원 관리 · 기기 무제한)

- Railway Variables(또는 환경변수)에 `MASTER_USERNAME`(영문 소문자·숫자·밑줄 4~20자)과 `MASTER_PASSWORD`(8자 이상)를 넣으면, 서버가 시작될 때 마스터 계정을 만들거나 비밀번호를 갱신합니다. 비밀번호는 코드·GitHub에 저장되지 않습니다.
- 마스터는 로그인 기기 수 제한이 없고, `/admin.html`(내 공간 › 회원 관리)에서 회원 검색 · 임시 비밀번호 발급 · 이용 정지/해제 · 삭제를 할 수 있습니다.
- 마스터 계정은 탈퇴·비밀번호 찾기·삭제가 막혀 있고, 비밀번호를 바꾸려면 `MASTER_PASSWORD` 값을 바꾸고 재배포하면 됩니다.

## 도구실

홈페이지 `도구실` 카테고리 → `/tools.html`
- **시작·휴식 타이머**: 시작 시간 / 휴식 시간 / 반복 횟수를 직접 설정, 일시정지·처음으로, 끝나기 3초 전·전환 소리, 화면 꺼짐 방지. 마지막 반복 뒤에는 휴식 없이 끝납니다. 설정은 이 브라우저에 기억됩니다.
- **메트로놈**: 20~300 BPM (슬라이더 · 숫자 입력 · ±버튼(길게 누르면 연속) · 탭 템포), 1~8박 한 마디, 첫 박 강세.
